# Olá, me chamo Wellington 👋

**Analista de Dados e BI** em Uberlândia, MG. Transformo dados de ERP em informação para decisão, com foco em **Power BI**, **SQL (PostgreSQL)**, **banco de dados / data lake** e **automação**.

Antes dos dados, foram mais de 10 anos em rotinas financeiras e fiscais: contas a receber, controladoria, auditoria de documentos e compliance. Por isso olho para cada indicador perguntando de onde o número vem e o que ele significa para a operação.
